# 🎯 My Study Table

**版本**: v0.1.12  
**技术栈**: 纯前端 HTML + CSS + JavaScript（Electron 可选）  
**数据存储**: localStorage（Electron 环境额外支持文件系统备份）  
**自动更新**: electron-updater（GitHub Releases 发布）  

My Study Table 是一款面向学习者的多功能桌面管理工具，集成了待办管理、笔记系统、日程追踪、AI 助手、计时器、习惯追踪、音乐播放器等功能，帮助你高效规划学习、记录知识、追踪进度。

## 1. 📋 待办管理

### 基础操作
- **新增待办** — 输入名称和可选截止日期，自动归入当前目录
- **子任务** — 每个待办可展开子任务输入框，支持无限层级嵌套
- **编辑** — 修改名称、截止日期、正文备注、标签
- **删除** — 带确认对话框，可选"不再提示"；删除前自动保存完成记录到历史日志
- **完成切换** — 点击复选框切换；完成父任务时级联完成所有子任务

### 层级与导航
- **无限层级树** — 支持任意深度的父子任务
- **展开/折叠** — 单个或一键全部展开/折叠
- **面包屑** — 显示当前目录路径，点击可返回任意祖先
- **目录信息面板** — 进入子目录时显示父任务的详情

### 搜索与筛选
- **实时搜索** — 按关键词搜索，结果含祖先路径，支持"去目录"跳转
- **隐藏已完成** — 一键切换隐藏/显示已完成待办
- **标签系统** — 每个待办可绑定多个标签，在列表中显示彩色徽章

### 进度统计
- **进度条** — 显示当前范围的完成百分比和计数

### 拖拽排序
- **三种放置区域** — before（上方）、after（下方）、child（成为子任务）
- **循环引用保护** — 防止将父任务拖入其子孙中

### 批量操作
- **多选模式** — 切换多选，点选多个待办
- **批量删除/编辑** — 统一修改名称、截止日期、标签、正文

### 撤销/重做
- **Ctrl+Z / Ctrl+Y** — 覆盖新增、删除、拖拽、完成切换等操作（最多 50 步）

### 计时关联
- 每个待办显示该任务及所有子任务的累计计时时间（10 秒以上显示）

## 2. 📝 笔记管理

### 笔记基础
- **创建/编辑/删除** — 支持多篇笔记，内容自动保存（500ms 防抖）
- **最后一条保护** — 不会删除最后一条笔记，而是清空内容

### 文件夹系统
- **多级文件夹** — 支持无限嵌套
- **内联重命名** — 像 Windows 资源管理器，点击名称直接编辑
- **右键菜单** — 新建笔记/文件夹、重命名/删除文件夹、跳过复习

### Markdown 格式工具栏
14 个格式化按钮 + 键盘快捷键：

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 粗体 | Ctrl+B | `**文字**`，选中可切换解包 |
| 斜体 | Ctrl+I | `*文字*` |
| 删除线 | Ctrl+U | `~~文字~~` |
| 行内代码 | Ctrl+K | `` `代码` `` |
| 标题 | — | `## 标题` |
| LaTeX 公式 | — | `\(公式\)` |
| 链接 | — | `[文字](url)` |
| 无序/有序列表 | — | `-` / `1.` |
| 引用 | — | `> 引用` |
| 任务列表 | — | `- [ ] 任务` |
| 分割线 | — | `---` |

### 编辑/预览/摘要三模式
- **编辑模式** — 文本编辑器 + 格式工具栏
- **预览模式** — 完整 Markdown + LaTeX 渲染（KaTeX 引擎 + `$$...$$` 块公式支持）
- **摘要模式** — AI 生成的笔记摘要（需配置 AI Key）

### AI 摘要
- **自动/手动** — 切换笔记或离开页面时自动触发，也可手动更新
- **状态指示** — 显示"最新"或"需要更新"

### 侧边栏
- **隐藏/显示** — 切换笔记列表侧边栏（240px），给编辑器更多空间

## 3. 🧠 复习系统（艾宾浩斯遗忘曲线）

### 间隔重复算法
基于艾宾浩斯遗忘曲线的间隔重复，复习间隔自动递增：

| 复习次数 | 间隔 |
|---------|------|
| 第 1 次 | 1 天 |
| 第 2 次 | 2 天 |
| 第 3 次 | 4 天 |
| 第 4 次 | 1 周 |
| 第 5 次 | 15 天 |
| 第 6 次 | 1 月 |
| 第 7 次 | 2 月 |
| 第 8 次+ | 4 月 |

### 功能
- **自动到期计算** — 基于复习历史自动计算下次复习日期
- **复习浮窗** — 非模态浮窗，可点击穿透、折叠/展开、自适应高度
- **prev/next 导航** — 自动跳转目标笔记，不关闭浮窗
- **日历日期详情** — 待复习笔记区块（逾期红色标记）
- **笔记列表徽章** — 显示"复习"（到期）、"X天"（即将到期）、"跳过"状态
- **一键复习** — 点击跳转到笔记模块打开该笔记
- **编辑自动重置** — 编辑笔记自动重置复习周期
- **跳过/恢复** — 右键菜单控制某笔记是否参与复习

## 4. ☀️ "今天"页面

每天打开应用的第一站，集中展示当日最重要信息。

### 长期目标
- **添加/编辑/删除** — 管理长期目标（非待办），支持正文、截止日期
- **计时关联** — 显示累计计时时间，计时器可独立关联目标
- **编辑弹窗** — 点击目标打开编辑弹窗

### 每日打卡
- **打卡按钮** — 一键记录今天学习，可多次打卡
- **连续天数** — 自动计算并显示连续天数
- **本周日历** — 显示本周每天的打卡状态
- **精确时间** — 每次打卡记录精确到分钟（HH:mm）
- **激励语** — 打卡后随机展示名人名言

### 日报系统
- **☀️ 晨间日报** — 打卡后自动生成：回顾昨天完成 + 开启今天方向。以"学习伙伴"风格提供有洞察力的写作建议。数据涵盖昨日待办/计时/笔记/逾期/复习/习惯
- **🌙 晚间日报** — 设置中可开启（默认 21:00），自动生成晚间回顾。以温暖风格总结当天、沉淀收获
- **独立对话标签页** — 日报在 AI 助手「📋 每日日报」标签页内展示

### 今日聚焦
- **聚焦列表** — 每天最多可设 2~5 个聚焦任务（设置中可调）
- **待办选择器** — 树形结构选择器从待办中挑选聚焦任务
- **展开/折叠** — 查看子任务
- **状态同步** — 聚焦完成状态与待办双向同步

### 笔记复习卡片
- **始终可见** — 无论是否有到期笔记，卡片始终显示
- **到期列表** — 列出所有待复习笔记（含轮次、逾期天数、摘要预览）

## 9. 🤖 AI 助手

### 对话管理
- **多对话标签页** — 独立上下文，可拖拽排序
- **对话设置** — 编辑标题、自定义 System Prompt
- **草稿保留** — 每个对话的输入内容独立保存
- **自动标题生成** — AI 根据内容自动命名对话（可开关、可指定 Key）

### 并行对话
- **独立加载/停止** — 切换标签页不干扰正在进行的对话
- **对话日志导出** — 完整消息、System Prompt、API 配置、深度思考、候选记录

### API Key 管理
- **多 Key 支持** — 同时配置多个 API Key（支持 OpenAI / DeepSeek / Kimi 等兼容 API）
- **独立配置** — 每个 Key 可设名称、Base URL、模型、温度、最大 Token、上下文条数
- **一键切换** — 工具栏下拉即时切换
- **Key 标注** — 每条 AI 回复标注使用的 Key 名称

### 对话功能
- **Markdown + LaTeX 渲染** — 完整排版支持（KaTeX 引擎）
- **深度思考** — 可折叠展示 AI 推理过程
- **附件上传** — 支持 .txt、PDF、Word、Excel、图片等
- **Kimi 视觉分析** — 图片/视频直接识别
- **停止响应** — 加载中可中断 AI 回复

### 多候选回复（DeepSeek 风格）
- **多版本候选** — 一条回复可生成多个候选版本
- **翻页切换** — `< 1/3 >` 导航浏览
- **换一条** — 追加新候选
- **采用本条** — 锁定当前选择作为后续上下文（候选保留可随时切换）

### 工具调用系统
AI 可通过 `<tool_call>` 标签直接操作应用数据：

**待办管理**: add_todo、batch_add_todos、update_todo、delete_todo、toggle_todo、move_todo、list_todos、get_todo_detail、batch_update_todos、get_todo_stats  
**聚焦与状态**: get_today_status、get_focus_tasks、set_focus_task、get_stats  
**笔记管理**: add_note、update_note、move_note、delete_note、list_notes、search_notes、get_note_detail、get_note_changes  
**快捷访问**: add_link、delete_link、list_links  
**自动化**: schedule_automation、list_automations、delete_automation  
**记忆**: list_memories、get_memory_detail  
**复习与习惯**: get_review_status、get_habits_status  
**搜索**: web_search（支持 5 种引擎）

### 多 AI 协作
- AI 可通过 `<call_ai>` 标签调用其他 Key 的模型
- 被调用 AI 的回复以独立消息显示，标注 Key 名称

### 定时自动化
- **AI 可创建定时任务** — 设置时间、描述、重复模式
- **自动触发** — 到达指定时间自动向对话发送触发消息
- **桌面通知** — 执行完成后发送系统通知

### 长期记忆系统
- **6 类记忆** — 事实、偏好与习惯、目标、能力、行为模式、心理模式，各有独立配色
- **实时提取** — 对话中通过 `<memory>` 标签实时提取关键信息
- **置信度算法** — 纯客户端运算（重复 +0.3 / 同向 +0.15 / 矛盾 -0.3 / 每日衰减 -0.02）
- **双层结构** — 简略信息（prompt 显示）+ 详细内容（展开查看）
- **每日整合** — AI 每日生成对话总结并更新用户画像（自由文本格式）
- **管理面板** — 设置中完整管理界面（筛选/编辑/详情/删除）

### 网络搜索
- **5 种引擎** — Brave Search、Tavily、SearchAPI.io、Exa、DuckDuckGo
- **按对话开关** — 工具栏胶囊按钮独立控制
- **独立 Key** — 各引擎可填专用 API Key

## 10. 🎨 外观与主题系统

### 主题预设
6 个内置预设 + 无限自定义预设：

| 预设 | 说明 |
|------|------|
| 默认 | 简洁原色 |
| 天空 | 蓝粉渐变 |
| 森林 | 绿调渐变 |
| 日落 | 暖橙渐变 |
| 薰衣草 | 紫调渐变 |
| 墨灰 | 中性灰调 |
| 磨砂玻璃 | 玻璃质感 |

### 自定义预设
- **保存为预设** — 将当前主题配置保存为新预设卡片
- **覆盖保存** — 修改预设后自动切换到自定义模式，复制预设全部有效值
- **删除自定义预设** — 右上角 ✕ 按钮

### 背景系统
- **五种背景类型** — 无 / 纯色 / 渐变 / 图片 / 视频
- **渐变编辑器** — 角度滑块（0~360°）+ 起止颜色选择器
- **图片背景** — URL 输入或打开本地文件（Electron Data URL 注入）
- **视频背景** — URL 或本地文件（无限大小），循环静音播放
- **覆盖层** — 不透明度滑块（0~100%）
- **背景模糊** — 0~20px，模糊背景层

### 强调色
10 色预选 + 自定义颜色拾取器

### 磨砂玻璃效果
- **完整玻璃 UI** — 侧边栏/卡片/弹窗/待办项/笔记项/工具栏/右键菜单等 14+ 元素统一毛玻璃质感
- **磨砂程度** — 0~50px 模糊半径
- **透明度** — 0~100%，100% 时面板近乎通透
- **明暗双适配** — 开关自动切换亮/暗色玻璃半透明方案

### 液态玻璃折射（Apple 风格）
基于 SVG `feDisplacementMap` 的 `backdrop-filter` 真实背景像素弯曲：

- **弯曲程度** — 边缘内容弯曲强度（0~60px 位移）
- **偏折程度** — 弯曲区域宽度（从边缘向内延伸多远）
- **顶层辉光** — 镜面高光亮度（多层 gradient + brightness 动态控制）
- **完整边缘定义** — ::after 四边色光边框 + 底部右侧环境反射
- **浮动阴影** — 玻璃面板下方柔和投影，增强悬浮感

> 仅 Chromium / Electron 支持 `backdrop-filter: url(#filter)`（Safari/Firefox 不适用）

## 15. 🔄 自动更新

应用通过 `electron-updater` 实现自动更新，发布渠道为 **GitHub Releases**。

### 更新机制

| 时机 | 说明 |
|------|------|
| 启动时 | 应用启动后 5 秒自动检查一次 |
| 定时 | 运行期间每小时自动检查一次 |
| 手动 | 设置 → 更多设置 → 软件更新 → 检查更新 |

### 支持的版本类型

- ✅ **NSIS 安装版** — 完整自动更新：后台静默下载安装包，弹窗显示下载进度，完成后一键「重启并安装」
- ⚠️ **便携版 / zip 解压版** — 不支持一键自动更新，会提示前往 GitHub Releases 手动下载最新版

> 注：未签名应用的安装程序在 Windows 上可能出现 SmartScreen 警告，属正常现象，选择"更多信息 → 仍要运行"即可。

### 发布新版本流程

1. **更新版本号** — 修改 `package.json` 的 `version`（如 `0.1.12`），同时更新 `js/settings.js` 中 `initChangelog()` 的更新日志
2. **配置发布源** — 编辑 `package.json` 中 `build.publish`，将 `owner` 改为你的 GitHub 用户名
3. **生成 GitHub Token** — GitHub → Settings → Developer settings → Personal access tokens，勾选 `repo` 权限
4. **构建并发布** — 执行 `build_app.bat` 选择 **[4] 发布构建**（或命令行运行 `npm run publish`，需先设置环境变量 `GH_TOKEN`）
5. **确认发布** — 构建完成后访问仓库 Releases 页面，确认生成对应版本号（`v0.1.12`）的 Release，并包含 `My Study Table Setup 0.1.12.exe` 与 `latest.yml`

### 常见问题

- **发布失败：未配置 GH_TOKEN** — 在 PowerShell 中执行 `$env:GH_TOKEN="你的token"` 后重试
- **检查更新报错** — 确认 `package.json` 的 `owner/repo` 与真实仓库一致，且新版本号高于当前安装版本
- **想要国内下载更快** — 可将 `build.publish` 换成腾讯云 COS / 自建静态服务器（provider 改为 `generic`），更新代码无需改动
