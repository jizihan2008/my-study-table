# 🎯 My Study Table

![License](https://img.shields.io/badge/License-Custom%20License-blue)

**版本**: v0.3.0  
**技术栈**: 纯前端 HTML + CSS + JavaScript（Electron 可选 / 手机端 PWA）  
**数据存储**: localStorage + CloudBase / 阿里云 Supabase 云同步（跨设备）
**自动更新**: electron-updater（GitHub Releases 发布）  

My Study Table 是一款面向学习者的多功能桌面管理工具，集成了待办管理、笔记系统、日程追踪、AI 助手、计时器、习惯追踪、音乐播放器等功能，帮助你高效规划学习、记录知识、追踪进度。

## 1. 📋 待办管理

### 基础操作
- **新增待办** — 输入名称和可选截止日期，自动归入当前目录
- **子任务** — 每个待办可展开子任务输入框，支持无限层级嵌套
- **编辑** — 修改名称、截止日期、正文备注、标签
- **删除** — 带确认对话框，可选"不再提示"；删除前自动保存完成记录到历史日志
- **完成切换** — 点击复选框切换；完成父任务时级联完成所有子任务

### 层级与导航
- **无限层级树** — 支持任意深度的父子任务
- **展开/折叠** — 单个或一键全部展开/折叠
- **面包屑** — 显示当前目录路径，点击可返回任意祖先
- **目录信息面板** — 进入子目录时显示父任务的详情

### 搜索与筛选
- **实时搜索** — 按关键词搜索，结果含祖先路径，支持"去目录"跳转
- **隐藏已完成** — 一键切换隐藏/显示已完成待办
- **标签系统** — 每个待办可绑定多个标签，在列表中显示彩色徽章

### 进度统计
- **进度条** — 显示当前范围的完成百分比和计数

### 拖拽排序
- **三种放置区域** — before（上方）、after（下方）、child（成为子任务）
- **循环引用保护** — 防止将父任务拖入其子孙中

### 批量操作
- **多选模式** — 切换多选，点选多个待办
- **批量删除/编辑** — 统一修改名称、截止日期、标签、正文

### 撤销/重做
- **Ctrl+Z / Ctrl+Y** — 覆盖新增、删除、拖拽、完成切换等操作（最多 50 步）

### 计时关联
- 每个待办显示该任务及所有子任务的累计计时时间（10 秒以上显示）

## 2. 📝 笔记管理

### 笔记基础
- **创建/编辑/删除** — 支持多篇笔记，内容自动保存（500ms 防抖）
- **最后一条保护** — 不会删除最后一条笔记，而是清空内容

### 文件夹系统
- **多级文件夹** — 支持无限嵌套
- **内联重命名** — 像 Windows 资源管理器，点击名称直接编辑
- **右键菜单** — 新建笔记/文件夹、重命名/删除文件夹、跳过复习

### Markdown 格式工具栏
16 个格式化按钮 + 键盘快捷键：

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 粗体 | Ctrl+B | `**文字**`，选中可切换解包 |
| 斜体 | Ctrl+I | `*文字*` |
| 删除线 | Ctrl+U | `~~文字~~` |
| 行内代码 | — | `` `代码` `` |
| 代码块 | — | ` ```语言 ` 围栏代码，支持语法高亮 |
| 标题 | — | `## 标题` |
| LaTeX 公式 | — | `\(公式\)` |
| 链接 | Ctrl+K | `[文字](url)`，外链经过协议校验 |
| 网络图片 | — | `![说明](https://...)`，懒加载且不发送来源页 |
| 无序/有序列表 | — | `-` / `1.` |
| 引用 | — | `> 引用` |
| 任务列表 | — | `- [ ] 任务` |
| 表格 | — | 插入 GFM 表格模板 |
| 脚注 | — | `[^1]` + `[^1]: 内容` |
| 分割线 | — | `---` |

### 编辑/预览/摘要三模式
- **编辑模式** — 文本编辑器 + 格式工具栏
- **预览模式** — CommonMark/GFM Markdown + KaTeX 渲染；支持嵌套列表、引用、表格、任务列表、删除线、链接、图片、脚注、标题锚点、代码高亮、`$$...$$` 块公式和内嵌思维导图
- **智能目录** — 自动提取 H1–H6 标题生成右侧层级目录，点击跳转并随滚动高亮当前章节
- **安全渲染** — 禁用原始 HTML，DOMPurify 二次消毒；外链仅允许 HTTP/HTTPS/Mailto，图片仅允许 HTTPS
- **摘要模式** — AI 生成的笔记摘要（需配置 AI Key）

### AI 摘要
- **自动/手动** — 切换笔记或离开页面时自动触发，也可手动更新
- **状态指示** — 显示"最新"或"需要更新"

### 侧边栏
- **隐藏/显示** — 切换笔记列表侧边栏（240px），给编辑器更多空间

## 3. 🧠 复习系统（艾宾浩斯遗忘曲线）

### 间隔重复算法
基于艾宾浩斯遗忘曲线的间隔重复，复习间隔自动递增：

| 复习次数 | 间隔 |
|---------|------|
| 第 1 次 | 1 天 |
| 第 2 次 | 2 天 |
| 第 3 次 | 4 天 |
| 第 4 次 | 1 周 |
| 第 5 次 | 15 天 |
| 第 6 次 | 1 月 |
| 第 7 次 | 2 月 |
| 第 8 次+ | 4 月 |

### 功能
- **自动到期计算** — 基于复习历史自动计算下次复习日期
- **复习浮窗** — 非模态浮窗，可点击穿透、折叠/展开、自适应高度
- **prev/next 导航** — 自动跳转目标笔记，不关闭浮窗
- **日历日期详情** — 待复习笔记区块（逾期红色标记）
- **笔记列表徽章** — 显示"复习"（到期）、"X天"（即将到期）、"跳过"状态
- **一键复习** — 点击跳转到笔记模块打开该笔记
- **编辑自动重置** — 编辑笔记自动重置复习周期
- **跳过/恢复** — 右键菜单控制某笔记是否参与复习

## 4. ☀️ "今天"页面

每天打开应用的第一站，集中展示当日最重要信息。

### 长期目标
- **添加/编辑/删除** — 管理长期目标（非待办），支持正文、截止日期
- **计时关联** — 显示累计计时时间，计时器可独立关联目标
- **编辑弹窗** — 点击目标打开编辑弹窗

### 每日打卡
- **打卡按钮** — 一键记录今天学习，可多次打卡
- **连续天数** — 自动计算并显示连续天数
- **本周日历** — 显示本周每天的打卡状态
- **精确时间** — 每次打卡记录精确到分钟（HH:mm）
- **激励语** — 打卡后随机展示名人名言

### 日报系统
- **☀️ 晨间日报** — 打卡后自动生成：回顾昨天完成 + 开启今天方向。以"学习伙伴"风格提供有洞察力的写作建议。数据涵盖昨日待办/计时/笔记/逾期/复习/习惯
- **🌙 晚间日报** — 设置中可开启（默认 21:00），自动生成晚间回顾。以温暖风格总结当天、沉淀收获
- **独立对话标签页** — 日报在 AI 助手「📋 每日日报」标签页内展示

### 今日聚焦
- **聚焦列表** — 每天最多可设 2~5 个聚焦任务（设置中可调）
- **待办选择器** — 树形结构选择器从待办中挑选聚焦任务
- **展开/折叠** — 查看子任务
- **状态同步** — 聚焦完成状态与待办双向同步

### 笔记复习卡片
- **始终可见** — 无论是否有到期笔记，卡片始终显示
- **到期列表** — 列出所有待复习笔记（含轮次、逾期天数、摘要预览）

## 5. 📅 日历视图

### 月视图
- **月份导航** — 上/下月、回到今天
- **今日高亮** — 当天日期特殊标记
- **角标系统** — 截止日期数量、完成数量、计时时长的三色角标

### 日历事件
- **彩色事件** — 每个日期可添加多个事件，8 种颜色可选
- **时间段** — 每个事件支持「开始时间 + 结束时间」（结束时间可留空，跨零点时自动顺延到次日），并提供备注
- **自动计入计时记录** — 勾选后，事件时段结束时自动补写一条计时记录：计入当天计时累计与日历角标，并弹出系统通知（需要填写结束时间；不足 1 分钟的时段不记账）
- **计入专注时间** — 关闭后自动补写的记录只计入当天计时累计，不计入专注时间统计（历史记录显示 ⚡ 徽章）
- **每周重复** — 可设为「每周重复」并直接勾选星期几（一/二/三/四/五/六/日，可多选，如每周一三五）；开始日期所在那一周整周算起点，重复事件带 🔁 标记，自动计入也逐个命中日生效
- **仅删除这一天** — 右键重复事件可只删掉当前这一天的场次，其它日期保留；被删的那天在详情里显示可一键「恢复」
- **事件圆点** — 日历格子显示彩色事件圆点（最多 4 个 + N），开启自动计入的事件带 ⏱ 标记
- **编辑/删除** — 点击事件可编辑；右键可编辑 / 仅删除这一天 / 删除整个事件（删除事件不会删除已生成的计时记录）
- **AI 可读写** — 对话 AI 可通过 list_calendar_events / create_calendar_event / update_calendar_event / delete_calendar_event / restore_calendar_event_date 查询和增删改日程（「对话设置 → 给 AI 的接口组 → 日历日程」）

### 日期详情
- **默认选中今天** — 打开日历自动选中并展开今天（本次会话内保留你的切换）
- **截止任务列表** — 显示选中日期的待办，支持直接勾选
- **完成记录** — 显示该日完成/已删除的待办，可手动删除单条记录
- **计时记录** — 显示该日的计时时段详情
- **待复习笔记** — 逾期笔记红色标记

## 6. ⏱️ 计时器

### 计时控制
- **开始/暂停/停止/重置** — 完整的计时控制
- **自动分段** — 每次暂停/恢复生成独立时段
- **关掉应用不丢时长、也不会自己跑起来** — 计时状态会持久化：
  - 刚关掉就重开（24 小时内）：自动接着计时，界面提示「已恢复上次未结束的计时」，只从重开这一刻继续，关掉期间的空白不计入
  - 隔了很久（超过 24 小时）才打开：只把上次的时长**找回并显示**（计时器停在「开始」上，不会被莫名启动），点「开始」继续或点「保存」记入记录
  - 窗口的 ✕ 只是隐藏到托盘，应用仍在运行、计时继续；从托盘真正退出时会把当前时长落盘

### 关联系统
- **关联待办** — 选择任意待办进行计时
- **关联目标** — 选择长期目标进行计时
- **独立双关联** — 可同时关联一个待办和一个目标，互不干扰

### 手动记录
- **添加/编辑/删除** — 手动记录专注时段（时间范围、时长）
- **关联待办/目标** — 手动记录支持关联
- **affectsFocus** — 控制是否计入聚焦统计
- **历史记录徽章** — 手动记录（✍）、日历自动计入（📅）和"不计入"（⚡）显示独立徽章

### 记录与历史
- **今日时段列表** — 显示今日所有计时时段（时间范围、时长）
- **历史记录** — 最近 14 天的计时数据，按日期分组
- **时段详情** — 展开查看每条记录的时段明细

## 9. 🤖 AI 助手

### 对话管理
- **多对话标签页** — 独立上下文，可拖拽排序
- **对话设置** — 编辑标题、自定义 System Prompt
- **草稿保留** — 每个对话的输入内容独立保存
- **自动标题生成** — AI 根据内容自动命名对话（可开关、可指定 Key）

### 并行对话
- **独立加载/停止** — 切换标签页不干扰正在进行的对话
- **对话日志导出** — 完整消息、System Prompt、API 配置、深度思考、候选记录

### API Key 管理
- **多 Key 支持** — 同时配置多个 API Key（支持 OpenAI / DeepSeek / Kimi 等兼容 API）
- **独立配置** — 每个 Key 可设名称、Base URL、模型、温度、最大 Token、上下文条数
- **一键切换** — 工具栏下拉即时切换
- **Key 标注** — 每条 AI 回复标注使用的 Key 名称

### 对话功能
- **流式回复** — 普通对话与重新生成默认逐字展示；完成后统一渲染 Markdown，降低生成等待感
- **安全停止** — 点击红色停止按钮会中断当前网络流，并保留已经收到的部分回复
- **Markdown + LaTeX 渲染** — 与笔记共用 CommonMark/GFM 安全渲染器，支持代码高亮、脚注、任务列表、表格、标题锚点和 KaTeX
- **深度思考** — 可折叠展示 AI 推理过程
- **附件上传** — 支持 .txt、PDF、Word、Excel、图片等；点附件按钮选择、从文件管理器拖拽，或在聊天区直接 **Ctrl+V 粘贴**（剪贴板里的文件与截图都行，无需先存盘）
- **Kimi 视觉分析** — 图片/视频直接识别
- **图片理解（DeepSeek Flash 等）** — `deepseek-flash` 支持图片内联（base64 image_url）分析；超大图自动缩放、BMP 等不支持格式自动转 PNG/JPEG
- **图片只传一次（DeepSeek 文件服务）** — 大图上传后每轮只发 `file_id`，同一张图多轮追问不再重复上传；可在设置里选择自动 / 总是上传 / 仅内联，并提供服务端文件清理入口
- **停止响应** — 加载中可中断 AI 回复

### 多候选回复（DeepSeek 风格）
- **多版本候选** — 一条回复可生成多个候选版本
- **翻页切换** — `< 1/3 >` 导航浏览
- **换一条** — 追加新候选
- **采用本条** — 锁定当前选择作为后续上下文（候选保留可随时切换）

### 工具调用系统
AI 可通过 `<tool_call>` 标签直接操作应用数据：

**待办管理**: add_todo、batch_add_todos、update_todo、delete_todo、set_todo_completed、move_todo、list_todos、get_todo_detail、batch_update_todos、get_todo_stats
**聚焦与状态**: get_today_status、get_focus_tasks、set_focus_task、get_stats  
**笔记管理**: add_note、update_note、move_note、delete_note、list_notes、search_notes、get_note_detail、get_note_changes  
**快捷访问**: add_link、delete_link、list_links  
**自动化**: schedule_automation、list_automations、delete_automation  
**记忆**: list_memories、get_memory_detail  
**复习与习惯**: get_review_status、get_habits_status  
**日历日程**: list_calendar_events、create_calendar_event、update_calendar_event、delete_calendar_event、restore_calendar_event_date
**搜索**: web_search（支持 5 种引擎）

> 工具按「接口组」下发给 AI，可在 AI 页的「接口组」胶囊或对话设置里逐组开关；删除类操作另有 block / confirm / allow 三档删除策略。

### 多 AI 协作
- AI 可通过 `<call_ai>` 标签调用其他 Key 的模型
- 被调用 AI 的回复以独立消息显示，标注 Key 名称

### 定时自动化
- **AI 可创建定时任务** — 设置时间、描述、重复模式
- **自动触发** — 到达指定时间自动向对话发送触发消息
- **桌面通知** — 执行完成后发送系统通知

### 长期记忆系统

## 15. 🔄 自动更新

应用通过 `electron-updater` 实现自动更新，发布渠道为 **GitHub Releases**。

### 更新机制

| 时机 | 说明 |
|------|------|
| 启动时 | 应用启动后 5 秒自动检查一次 |
| 定时 | 运行期间每小时自动检查一次 |
| 手动 | 设置 → 更多设置 → 软件更新 → 检查更新 |

### 支持的版本类型

- ✅ **NSIS 安装版** — 完整自动更新：后台静默下载安装包，弹窗显示下载进度，完成后一键「重启并安装」
- ⚠️ **便携版 / zip 解压版** — 不支持一键自动更新，会提示前往 GitHub Releases 手动下载最新版

> 注：未签名应用的安装程序在 Windows 上可能出现 SmartScreen 警告，属正常现象，选择"更多信息 → 仍要运行"即可。

### 发布新版本流程

1. **更新版本号** — 修改 `package.json` 的 `version`（如 `0.1.12`），同时更新 `js/settings.js` 中 `initChangelog()` 的更新日志
2. **配置发布源** — 编辑 `package.json` 中 `build.publish`，将 `owner` 改为你的 GitHub 用户名
3. **生成 GitHub Token** — GitHub → Settings → Developer settings → Personal access tokens，勾选 `repo` 权限
4. **构建并发布** — 执行 `build_app.bat` 选择 **[4] 发布构建**（或命令行运行 `npm run publish`，需先设置环境变量 `GH_TOKEN`）
5. **确认发布** — 构建完成后访问仓库 Releases 页面，确认生成对应版本号（`v0.1.12`）的 Release，并包含 `My Study Table Setup 0.1.12.exe` 与 `latest.yml`

### 常见问题

- **发布失败：未配置 GH_TOKEN** — 在 PowerShell 中执行 `$env:GH_TOKEN="你的token"` 后重试
- **检查更新报错** — 确认 `package.json` 的 `owner/repo` 与真实仓库一致，且新版本号高于当前安装版本
- **想要国内下载更快** — 可将 `build.publish` 换成腾讯云 COS / 自建静态服务器（provider 改为 `generic`），更新代码无需改动

## 16. 🧩 扩展系统与 AI 编程助手

扩展系统允许你在**不修改核心源码**的前提下为应用新增或修改功能，并支持用 **AI 自动生成扩展代码**。所有扩展存放在用户数据目录 `~/.my-study-table/extensions/<id>/`，可随时装载 / 卸载 / 回滚。

### 两类扩展

| 类型 | 作用 | 实现方式 | 风险 |
|------|------|----------|------|
| **plugin（安全插件）** | 新增功能：注册侧边栏项、新面板、工具栏按钮、订阅事件、独立数据区 | 通过受限 `extAPI` 白名单接口 | 低（不碰核心） |
| **patch（源码补丁）** | 修改现有功能：覆盖任意全局函数改变行为 | `PatchEngine` 运行时函数覆盖，卸载自动恢复原函数 | 中（需审阅代码） |

### AI 编程助手（CodeBuddy CLI Agent 模式）

侧边栏「AI 编程」页面，输入自然语言需求，通过**本机 CodeBuddy CLI** 运行 Agent 全栈式开发扩展：

```
输入需求 → 检测 CodeBuddy CLI →（缺失则一键安装）→ 运行 Agent
→ Agent 自主读取源码 / 写扩展文件（流式日志实时可见）
→ 自动备份 → 重新装载 → 完成
```

- **仅 CodeBuddy CLI 执行引擎**：Agent 具备完整能力（自动读文件、改文件、多步推理），真正全栈式完成扩展开发，而非只返回一段代码文本
- **权限边界**：Agent 工作目录 = 扩展目录（可读写）；应用源码目录只读（`--add-dir` 挂载 + 只允许 Read/Edit/Write 工具）；打包版自动导出源码快照供参考
- **一键安装**：本机无 CLI 时，AI 编程页 / 设置页提供「一键安装」（`npm install -g @tencent-ai/codebuddy-code`，可勾选国内镜像）
- **授权**：复用本机已登录的 CodeBuddy 凭据，或配置 CodeBuddy API Key（设置 → AI 设置 → CodeBuddy CLI）
- **每次运行前自动备份全部扩展** — 修改可回滚；Agent 覆盖已有扩展前自动备份，可在「扩展」页恢复

> 首次使用：需本机安装 Node.js ≥ 18.20，并安装 `@tencent-ai/codebuddy-code`；在终端运行一次 `codebuddy` 完成微信/QQ 登录（或配置 CodeBuddy API Key）。

## 17. 📱 手机端 PWA（跨设备）

手机端采用 **PWA（渐进式 Web 应用）**，复用同一套前端代码，改造为响应式移动布局，部署到云端后手机浏览器可直接访问，并支持「添加到主屏幕」获得类原生体验。手机端与桌面端共用同一套学习数据，通过 **Supabase 双向云同步**保持一致；PDF 电子书原文通过 **WebRTC 局域网传输**（类似 LocalSend）。

### 一、部署

将项目静态文件（`index.html`、`css/`、`js/`、`lib/`、`manifest.webmanifest`、`service-worker.js`、`icons/`）部署到任意静态托管平台（EdgeOne Pages / CloudBase / GitHub Pages / Vercel 等）。要求 **HTTPS**（Service Worker 与添加到主屏幕需要）。

### 二、云同步设置

1. 手机端与桌面端都使用「好友」系统中配置的同一云服务账号登录。
2. 在「设置 → 同步」面板开启云同步。
3. 首次同步：桌面端（本地已有数据）自动上传，手机端（新设备）自动拉取；之后双端在前台按低频轮询合并变更。

**同步范围**：待办、笔记、计时记录、习惯、任务线、电子书元数据（含章节摘要）、日历、统计等学习数据。

**绝不上传**：AI 对话 API Key、云服务配置、邮箱授权码等敏感凭据（仅存各自本地）。手机端 AI 对话可独立配置自己的 API Key。

阿里云 Supabase 免费版：在 Dashboard 的 SQL Editor 执行 `cloudbase/schema.sql`，然后进入“设置 → 云服务连接”，选择“阿里云 Supabase 免费版”并填写 `SUPABASE_URL` 与 `SUPABASE_ANON_KEY`。该兼容 Schema 不依赖免费实例禁用的 `SECURITY DEFINER`。

### 三、WebRTC 传输 PDF

1. **桌面端**：打开「教材 → 书架」，点书籍上的「发送到手机」按钮，得到 6 位配对码。
2. **手机端**：打开「教材 → 从桌面传输」，输入配对码点「开始接收」。
3. 双方通过 Supabase Realtime 配对信令 + WebRTC DataChannel（64KB 分片）局域网直连传输，手机端保存到本机（IndexedDB），之后可**离线阅读**，并支持章节摘要页码跳转。

> 注意：WebRTC 依赖双方处于同一局域网（或 NAT 可直连）；PDF 文件不出本地网络，不占云存储空间。

### 四、桌面专属功能

收件箱（IMAP）、编程 AI（CodeBuddy CLI / 扩展系统）、长截图等依赖 Electron 专属能力的功能，在手机端 **隐藏入口**，不提供支持。

### extAPI 接口（插件可用的白名单能力）

| 方法 | 说明 |
|------|------|
| `extAPI.registerNavItem({id, icon, label})` | 注册侧边栏导航项 |
| `extAPI.registerSection({id, html, render})` | 注册独立面板（html 为面板内容，render 为切页时回调） |
| `extAPI.addToolbarButton({icon, label, onclick})` | 注册工具栏按钮 |
| `extAPI.on(event, handler)` | 订阅应用事件 |
| `extAPI.emit(event, data)` | 触发事件 |
| `extAPI.getData(key)` / `setData(key, value)` | 读写扩展私有数据（`study_ext_<id>_<key>`） |
| `extAPI.notify(title, body)` | 发送系统通知 |
| `extAPI.log / warn / error` | 带扩展前缀的日志 |
| `extAPI.callCore(fnName, ...)` | 调用白名单核心只读函数（`loadData` / `getSettings` / `getEffectiveApiConfig` / `loadApiKeys`） |
| `extAPI.openExternal(url)` | 用系统浏览器打开链接 |

**生命周期钩子：** 在 main.js 中定义 `window['<扩展id>_mount'] = function(){...}`，扩展被装载时自动调用。

### PatchEngine（补丁引擎）

```js
// 包装原函数（wrapper 可调用 original）
PatchEngine.wrap('my-patch', window, 'renderToday', function(original, self, args) {
  // 前置逻辑
  const ret = original.apply(self, args);
  // 后置逻辑
  return ret;
});

// 完全替换
PatchEngine.override('my-patch', window, 'someFunction', function() { ... });

// 卸载时自动恢复，也可手动：PatchEngine.revertExt('my-patch')
```

### 插件示例（hello 插件）

```js
extAPI.registerNavItem({ id: 'hello-panel', icon: 'hand', label: '你好插件' });
extAPI.registerSection({
  id: 'hello-panel',
  html: '<div class="card"><div class="section-header"><span class="section-title">👋 你好插件</span></div><div id="helloBody">这是我用扩展系统做的新面板！</div></div>'
});
extAPI.on('app:ready', function () {
  extAPI.notify('你好插件', '应用已就绪，插件已装载！');
});
window['hello-panel_mount'] = function () { console.log('hello 插件装载完成'); };
```

### 安全说明

- 扩展运行在渲染进程，受 `contextIsolation` + `nodeIntegration:false` 保护，**无法直接访问文件系统**
- 扩展文件读写全部走主进程 IPC 白名单（仅限扩展目录内部）
- AI 生成的代码应用前可预览，应用后可在「扩展」页中随时禁用 / 卸载 / 回滚
