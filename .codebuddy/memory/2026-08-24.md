## 降 IO 优化（Supabase 磁盘 IO 预算耗尽应对，v20260824-r1/friends + core）
- 背景：Supabase 团队邮件提示项目磁盘 IO 预算耗尽（症状=请求 504 网关超时、ERR_CONNECTION_CLOSED、实例无响应）。此前的 504/好友页打不开很可能就是它导致（curl 直连健康检查正常，但 auth token 刷新/study_stats/profiles 查询走真实磁盘 IO 被卡）。
- 代码 IO 消耗源排查：①`startFriendsHeartbeat` 60s 心跳每次 auth.getUser()+profiles.update（**最可疑**，切走页面后仍后台跑）；②`syncStudyStats` 每次进好友页/刷新都 study_stats select+upsert+逐条 activities insert；③sync.js 30min 全量拉取 + Realtime debounce；④sync-logs.js gzip 分片上传。
- 实施的三项优化（`js/friends.js` + `js/core.js`）：
  1. **心跳降频 + 可见才写**：60s→5min；`friendsHeartbeat` 先检查 `#section-friends.active`，不可见直接 return（不在场不写库）。
  2. **syncStudyStats 增量写入**：云端今日记录存在且 checkin/focus_ms/todos_done/habit_count/streak 全一致 → 跳过 upsert。
  3. **切走好友页停止心跳**：`switchTab` 非 friends 时 `stopFriendsHeartbeat()`，回到 friends 时 `startFriendsHeartbeat()`。
