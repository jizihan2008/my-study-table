# 2026-08-05

## 好友系统（Supabase 后端）v0.3.0
新增联网好友系统，一期完整实现（账号+好友+分组+动态+聊天），版本从 0.2.1 → 0.3.0。

### 数据库
- `supabase/schema.sql`：profiles / friend_groups / friendships / study_stats / activities / conversations / messages 共 7 表，全部 RLS（`is_friend()` 辅助函数），注册触发器 `handle_new_user`（从 raw_user_meta_data 建 profile），最后 `alter publication supabase_realtime add table ...` 开启 Realtime。
- 使用前提：在 Supabase 控制台执行该脚本；Auth → Email 建议关闭 "Confirm email"（否则注册后需邮件确认）。

### 前端
- `js/friends.js`（新）：配置(get/saveFriendsConfig, key `study_friends_config`)、Supabase 客户端单例(getSupabaseClient, window.supabase UMD)、认证(register/login/logout/getSession/getMyProfile)、分组(create/rename/delete/assign)、好友(search/send/respond/remove)、聚合统计(computeDailyStats/syncStudyStats)、动态流(loadActivities/subscribeActivities)、在线心跳(60s 更新 profiles.last_seen)、UI 渲染(renderFriends/setup/login/home 三态)。
- `js/friends-chat.js`（新）：会话(getOrCreateConversation, 规范化 user_a<user_b)、消息(load/send/markRead)、Realtime 订阅、未读数、聊天 UI、好友资料卡(7日聚合统计)、删除好友。
- `index.html`：新增 `section-friends`（card padding:0, #friendsApp）、侧边栏 nav、脚本 supabase.js + friends.js + friends-chat.js、设置页新增「好友」tab(settingsPanelFriends)。
- `js/core.js`：ALL_NAV_ITEMS 新增 `{id:'friends',icon:'users',label:'好友'}`；switchTab 新增 friends 分支。
- `js/settings.js`：loadFriendsSettings/saveFriendsSettings；changelog 新增 id:19 (v0.3.0)；switchSettingsTab/openSettingsModal 挂 friends 分支。
- `css/style.css`：新增好友系统全部样式（fr-* 前缀）。

### 好友可见内容扩展（用户需求：标题级动态）
- **新表 `weekly_focus_todos`**（schema.sql）：user_id / week_start(周一) / todo_id / title / focus_ms，`unique(user_id, week_start, todo_id)`，RLS 仅本人+好友可读，已加 GRANT + realtime。**需重新执行 schema.sql 建表**。
- **新动态类型**（syncStudyStats 扩展，去重 key 复合 `todo:<id>`/`note:<id>`）：
  - `todos_done`：今日完成待办逐条发布「完成待办「标题」🎯」（getTodayCompletedTodos 从 study_todos_v2 取 completedAt===today）
  - `note_edit`：今日编辑笔记发布「编辑笔记「标题」」+ meta.summary（前 60 字去 Markdown 语法，getTodayEditedNotes 从 study_notes_v2 按 updatedAt/createdAt 判今日）
- **资料卡「本周专注 Top5 待办」**：friends.js `computeWeeklyTopTodos()`（study_timer_records 中 date∈[周一,今天] 且 affectsFocus，targetType 非 todo 排除，从 todos 补标题，取 top5）→ upsert weekly_focus_todos；friends-chat.js `frShowFriendProfile` 查该表按 focus_ms 倒序显示（.fr-profile-top-* 样式）。
- 动态流渲染：`note_edit` 在 content 下追加 `.fr-feed-note-summary`（左竖线摘要）。
- 隐私变化：待办标题、笔记标题+摘要、计时 top5 标题现会上传云端，仅好友可见（RLS 保证）。

### 关键实现点/坑
- 加载顺序：supabase.js(UMD) → friends.js → friends-chat.js（在 updater.js 后、扩展系统前）。settings.js 在 friends.js 之前加载，但 getFriendsConfig 是运行时调用，无冲突。
- `renderFriendsFeed` 被 `renderFriendsFeedView` 取代，两处订阅回调里必须用 `renderFriendsFeedView` + 手动 innerHTML 更新。
- 隐私：只同步聚合统计（打卡/专注毫秒/完成数/习惯次数/连续天数），不上传具体待办/笔记内容；靠 RLS 保证仅本人+好友可见。
- 聚合数据来源：study_checkin、study_timer_records(affectsFocus!==false)、study_todos_v2+study_todos_trash(completedAt)、study_habits_v2(checkins)。
- `friendsOpenChat`/`friendsCloseChat` 等跨模块函数挂在全局（顶层 function 声明）。
- 本模块依赖 node_modules/@supabase/supabase-js（`npm.cmd install --no-save`），UMD 已拷到 lib/supabase/supabase.js（210KB），lib/**/* 已被 electron-builder 打包。
- 修改 js/css 后须完全重启 Electron 才生效；当前未实际连接真实 Supabase 项目测试（需要用户提供 url+key）。
