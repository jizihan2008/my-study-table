## 第一轮改动（2026-07-20 r1）

### 习惯界面新增「为昨天打卡」功能
- **需求**：在习惯卡片中新增昨天补打卡入口，允许用户为前一天的习惯补充打卡记录
- `js/habits.js`：

  - `habit.checkins` 中的 yesterday 计数会自然参与 streak / heatmap / weekly 计算，无需额外处理
- `css/style.css`：新增 `.habit-yesterday-area` / `.habit-yesterday-header` / `.habit-yesterday-tag` / `.habit-yesterday-actions` / `.habit-yesterday-btn` / `.habit-yesterday-decr` 全套样式，与现有 today check-in 风格统一
- `index.html`：habits.js → r1，style.css → r1
