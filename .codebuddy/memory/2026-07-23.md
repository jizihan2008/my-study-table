**r32 展开动画修复**：用户反馈折叠平滑但展开不平滑。根因：`max-height: 3000px` 固定值，从 0→3000 在 0.5s 内完成，实际内容 ~200px 在动画前几帧就走完了，视觉上瞬间出现。

修复方案 — JS 动态 scrollHeight 驱动：
- `toggleTimerHistory()` 拆分两路：
  - **展开**：`renderTimer()` 后通过 `requestAnimationFrame` 找到新 body，设 `max-height:0` → 强制回流 → 设 `max-height: scrollHeight + 'px'` → transitionend 清理为 `''`
  - **折叠**：先对现有 DOM body 设 `max-height: scrollHeight` → 强制回流 → 设 `0` → transitionend 后 `renderTimer()` 重建 DOM
- CSS 保持 `transition: max-height 0.5s` 不变（JS 动画借力 CSS transition）
- 事件监听用 `{ once: true }` 自动清理
- 版本号：`20260723-r6` (timer.js)
