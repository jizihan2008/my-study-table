- `lib/pdfjs/`：pdfjs-dist v6.2.108 legacy build（`npm.cmd install pdfjs-dist --no-save` 后拷贝）。**注意 v6 只有 ESM（.mjs）**，用 `<script type="module">` 预加载挂 `window.pdfjsLib`；必须同时保留 `pdf.worker.mjs`（未压缩版）供 pdf.js fake worker 动态 import 兜底（实测只拷 min 版会报 "Cannot find module pdf.worker.mjs"）。
- `js/books.js`：数据模型（`study_books_v1`）、书架三栏工作台、章节树、导入/删除/重导入、正文缓存惰性访问、检索分词（中文 bigram + 英文词，terms 需 map term/def 字段不能直接 join 对象）。
- `js/books-pdf.js`：`parsePdfFile`（pdf.js 逐页提取 textContent + outline）、`splitChaptersByOutline`（outline→章节，同页章节自动合并）、`aiSplitChapters`（无书签时 AI 识别，JSON `{chapters:[{title,startPage}]}`）、正文缓存读写（`<userData>/books/<bookId>.json`）。`ensurePdfJs()` 动态 import 兜底时用 `document.baseURI` 构造绝对 URL（经典脚本里 import() 相对路径基准有歧义）。
- `js/books-kb.js`：`bkRenderKbPanel`（进度条+按钮）、`bkStartKbBuild`（串行逐章调 callAiApi，每章立即落盘→断点续跑，中断标志）、`bkStopKbBuild`、`bkRetryChapter`。每章输出 `{summary,terms[],keyPoints[],mindmap}`。
- `js/books-ai.js`：四 tab（章节讲解/全书问答/测验练习/摘要导图）+ 一键存笔记。讲解/问答=知识库+原文片段拼 prompt（`bkSnippet` 截断控 token）；测验=AI 出题 JSON（choice 本地判分/short AI 批改）+ `quizRecords` 历史；笔记联动自动建「教材学习」文件夹。

- `css/style.css`：`.bk-*` 全系列样式（三栏 `.bk-layout`/书架/章节树/对话卡/测验卡/摘要导图/进度条，聊天类 body 加 `.bk-body-chat` 使消息区独立滚动、输入框固定底部）。

### 关键坑（已解决）
1. pdfjs-dist v6 无 UMD，只能 ESM；需 worker 的未压缩版 `pdf.worker.mjs` 兜底。
2. `bkSearchChapters` 中 terms 是对象数组，必须 `.map(t=>t.term+' '+t.def)` 否则 join 出 `[object Object]`（已用临时测试 `_bk_test.js` 验证并修复，测试文件用户拒绝删除、保留在仓库根）。
3. import() 在经典脚本中的相对路径基准歧义 → 用 `new URL(rel, document.baseURI)` 构造。
