## 教材目录页解析（books-pdf.js r2-r8 + books.js r21）持续迭代

**核心功能**：从原书目录页（Contents）解析完整章节层级（替代不完整的书签 outline）。

**关键坑与修复**：
1. **目录页收集范围**：从含 "Contents"（含间隔式 `C O N T E N T S`）的页开始连续收集。**必须用 `tocStarted` 永久守卫**——目录区结束后（isBody 触发）`tocActive=false` 但 `tocStarted` 保持 true，否则**正文中出现的 "contents" 单词会重新激活收集**，误收集到书末 Index 页（如 Sipser 书 `2.2 PUSHDOWN AUTOMATA 121` 这种大写 Index 条目）。
2. **isBody 停止条件**：遇 `chapter \d+ /`（正文页眉，含斜杠）、间隔式 `p r e f a c e`、`acknowledg`、`^\s*copyright`、`^\s*selected bibliography`、`^\s*index` 停止。注意**不能把 "CONTENTS" 当停止信号**（目录续页也以 "CONTENTS"+页码开头），否则漏后续目录（如 Sipser Part Two 缺 3.2/4/5/6）。`isBody` 需 `tocTexts.length > 0` 守卫（避免误伤目录首页）。
3. **目录点线（dot leaders）清理**：条目 `标题 ....... 页码` 需截断到第一个 `. .`，否则标题残留点线。
4. **Part 层级支持**：识别 `Part One: 标题 页码`（英文序数/罗马数字/数字），树层级自适应：有 Part 时 `Part(0)→章(1)→节(2)→小节(3)`，无 Part 时 `章(0)→节(1)→小节(2)`。
5. **章节标号**：标题带标号（`1.1 Introduction`、`4.6.1 Properties...`），用 `withNum(num,title)`。
6. **过滤**：STOP_WORDS（of/and/the/Preface 等孤立词）+ hasRealTitle（章标题需 ≥3 字母词）。
7. **颗粒度选择**：`bkAskChapterGranularity` 支持 `source` 参数（'toc'/'outline'），层级按钮显示语义名（Part/章/节/小节），默认选中章层并展开预览。
8. **切分 bug**：AI 切分原用 `else if` 挂在 outline 分支的 else 上，目录/书签成功时会误触发 AI——改为独立 `if (!chapters && ...)`。

**真实代码测试方法**：Node 中 `(0,eval)(readFileSync('books-pdf.js'))` 加载真实全局函数（mock window/pdfjsLib/genId），调用 `parsePdfFile`/`parseContentsFromToc`/`splitChaptersAtLevel` 验证。比复制逻辑到测试脚本可靠（脚本可能和实际代码有差异）。

## 目录层级识别·缩进辅助（books-pdf.js r8→r9，2026-08-13）

**目标**：原 `parseContentsFromToc` 仅靠章节编号（1/1.1/1.1.1）判断层级，无编号条目不准确。用户要求**用目录原文的文本缩进（x 坐标）识别层级**。

**改动**：
1. **收集阶段保留原始 x 坐标**（parsePdfFile 内）：目录页按 y 分行时，每行前缀编码其**原始最小 x**（`\t<minX>\t文本`），不在收集阶段归一化（避免页脚/页码 x≈0 噪声污染整页基准）。原实现用 `(行x-页minX)/8` 会因页脚 x=0 导致全部深度被 clamp 到 5。
2. **解析阶段全局聚类**（parseContentsFromToc）：收集所有行 x → 去重排序 → 按间隙 ≥6px 分组，组序号即缩进深度 indent。章/节/小节缩进差（如 Sipser 138→153→186）正确聚类。
3. **缩进辅助判定**：用带编号条目校准 `chapterIndent`/`sectionIndent`（章的典型缩进、节的典型缩进）。**无编号条目**（如 Sipser 的 `Big-O and small-o notation`、`Formal definition of...`）若缩进比「节」深 → 归属当前节下作为更深小节（L3）；否则（与节平级，如 Summary/Problems）→ 归属当前章下作为章的子节点（L1）。

**验证（真实代码测试，两本 PDF）**：
- 概率论第10版（无 Part）：树正确，章→节→小节→无编号尾部，无回归。
- Sipser 第3版（有 Part）：**无编号小节正确缩进归位**——`7.1 Measuring Complexity` 下的 `Big-O and small-o notation` 等从原「与节平级」改为「节的 L3 子级」，这是本次核心改善。

**版本**：books-pdf.js `r9`（index.html `?v=20260813-r9`）。

**坑**：命令行传中文路径/中文用户目录在 PowerShell 会被 GBK 编码破坏（`纪子涵`→`绾子涵`）。绕开方式：脚本内硬编码绝对路径 + Node `-e` 用 `\u7eaa\u5b50\u6db5` 转义拷贝到无中文临时目录（`C:\temp_mst_test`）再运行，测完清理。

## 图注识别重构：坐标行首锚定 + 正文引用动词过滤（A+B，2026-08-13）

**背景**：对《算法导论第四版》341/343/344 页诊断发现 (1) **XObject 方案无效**——全书插图是矢量绘制（constructPath+setFillRGBColor），`paintImageXObject` 全 0，方案 C 废弃；(2) 旧整页 join 正则会把行中引用 "In Figure 12.2(d), the successor..." 误报为图注；(3) 343 页存在"行首 Figure 12.3 shows how TREE-INSERT works"正文段落，纯行首锚定（A）仍会误报，需叠加 B。

**改动**（books-pdf.js，index.html `?v=20260813-r3→r4`）：

  1. 按 `transform[5]`（y）容差 4px 聚合成行 → 行内按 `transform[4]`（x）排序；
  2. 行内按 x gap **>40px** 拆栏片段（双栏/多栏独立判断），每片段行首锚定 `^(?:Figure|Fig(?:ure)?\.?|图)\s*编号`；

## 知识库构建全局队列（books-kb.js r8→r9、books.js r5→r6、css r10→r11、SW mst-v8→v9，2026-08-13）

**需求**：构建知识库加队列——支持多本书/多任务排队，串行依次构建（原全局 `bkKbBuilding` 布尔锁一次只能构建一本书，第二本点构建被静默忽略）。

**核心**：
- 任务结构 `{ bookId, mode:'full'|'rebuild'|'chapter', chapterId?, detailLevel }`，队列 `bkKbQueue`，当前执行任务 `bkKbCurrentTask`（已 shift 出队）。
- `bkKbEnqueue(task)`：**同书同类型去重**（String 宽松比较 bookId + mode + chapterId），入队后调 `bkKbProcessQueue()`。
- `bkKbProcessQueue()`：空闲时 shift 队首 → 执行 → finally 后若队列非空继续递归。**执行前按 bookId 取书，书已删除则跳过该任务**。
- 入口改造：`bkStartKbBuild`/`bkBuildChapter` 由 async 构建体改为**同步入队**（仍做 cfg/API Key 校验）；执行体抽为 `_bkRunBookBuild(book, detailLevel)` / `_bkRunChapterBuild(book, ch, detailLevel)`（由队列调度，勿直接调用）。
- `_bkBuildChapterCore(book, ch, ...)` **增加 book 参数**（原内部 `bkGetActiveBook()` 会导致排队构建非激活书时错建到当前书）。
- `bkStopKbBuild()`：停止当前任务（章节边界 break）+ **清空等待队列**（停止即不再继续后续任务）。
- `bkRebuildKb()` 确认后 `bkKbEnqueue({mode:'rebuild'})`（重置 pending 在入队时完成）。
- `bkRefreshKbUi()`：统一刷新 面板+目录+书架（`bkRenderShelfList`），队列变化/每章构建完都调用，保证书架「排队中/构建中」徽章实时。

**UI**：
- 知识库面板顶部队列条 `bkRenderKbQueueBarHtml()`：当前执行任务（running 高亮）+ 等待任务列表（每个可「×」移出 `bkKbRemoveTask(idx)`）+「清空队列」`bkKbClearQueue()`。
- 书架徽章新增「排队中」（`.bk-badge-queued` 橙色，与 building 同色系）。
- 「停止构建」按钮仅当**正在构建本书**时显示（`buildingThisBook`），正在构建别书时本书可正常入队。
- 构建确认弹窗在队列非空时提示「将加入构建队列」。

**坑**：(1) 并行 replace_in_file 编辑同一文件会写锁超时，须串行；(2) 中文路径在 PowerShell 临时脚本 GBK 乱码，用 `"$env:USERPROFILE\..."` 展开绕开；(3) `bkStartKbBuild`/`bkBuildChapter` 改同步后所有调用点（books-ai.js onclick/重构建）均不 await 返回值，无兼容问题；(4) books-ai.js 的 `bkRebuildChapter`/`bkRegenerateSummary` 守卫 `bkKbBuilding` 保持原样（构建中禁止单章重操作）。
