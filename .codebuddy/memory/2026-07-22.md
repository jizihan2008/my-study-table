## 折射效果重写：Apple 风格边缘色散 (2026-07-22-r17)

用户反馈 r16 的全局 `brightness(1.08) contrast(1.04)` 完全看不出来。Apple 真正的折射效果在**边缘**——镜片边缘产生色散（chromatic aberration）。

**核心思路**：用 `inset box-shadow` 多层叠加在 `::before` 伪元素上，模拟透镜边缘的光学效果：
- 顶部/左边缘：亮白色高光（光线进入透镜方向）
- 右边缘：蓝色偏转（短波长弯曲更多）
- 底部边缘：暖色/紫色偏转（长波长）
- 四周：暗角（透镜曲率导致边缘变暗）

**CSS 改动 (`css/style.css`)**：
- 移除全局 `backdrop-filter` 中的 `var(--glass-refract-bf, brightness(1) contrast(1))`——body backdrop-filter 只保留 `blur+saturate`
- `::before` 改为 `box-shadow` 多层堆叠（10 层 inset shadow），按面板类型（sidebar/card/modal）有不同参数
- `::after` 保留顶部高光线（`linear-gradient` 向下衰减），作为方向性光提示
- 两者 `opacity: var(--glass-refract, 1)` 控制整体折射强度
- 暗色模式各 alpha 降低约 40%
- 所有效果均为 `inset`（在 `overflow:hidden` 内可见）

**JS 改动 (`js/settings.js`)**：
- `applyGlassRefract(percent)` 简化为直接设置 `--glass-refract: 0~1`（控制伪元素 opacity）
- 移除 `--glass-refract-bf`（backdrop-filter 已不再使用 brightness/contrast）

- 版本号：`20260722-r17`

## 折射三改：::before backdrop-filter + mask 边缘聚焦背景像素 (2026-07-22-r18)

用户指出 r17 的 `inset box-shadow` 白色/蓝紫色本质上还是模拟「光照在玻璃表面」，而不是折射背后的内容。真正折射应该对**背景像素**做边缘聚光。

**新方案**：
- `::before` 伪元素有自己独立的 `backdrop-filter: brightness(1.2) saturate(2) contrast(1.06)` — 真正处理背景像素
- 通过 `mask-image: radial-gradient(ellipse 78% 78%, transparent 0-55%, black 80%)` 只在边缘可见
- 中心区域 (0-55%)：mask 透明 → 普通磨砂玻璃（主面板的 blur+saturate）
- 边缘区域 (55-80%)：mask 渐变过渡 → 背景内容更亮(+20%)、更鲜艳(2x饱和度)、更锐利(+6%对比度)
- 模拟物理透镜：边缘聚光，背景内容透过透镜边缘时变亮变艳
- 暗色模式下参数降低 (brightness 1.14, saturate 1.6, contrast 1.04)
- 完全移除 `::after`（不再需要表面高光线，那是模拟光照不是折射）
- 完全移除所有 `box-shadow` 层（同理）

**JS 无需改动**：`--glass-refract` 仍控制 `::before` 的 opacity（0~1）。

- 版本号：`20260722-r18`

## 液态玻璃：SVG feDisplacementMap 真正弯曲背景像素 (2026-07-22-r19)

经过研究 Apple Liquid Glass 实现（kube.io/blog/liquid-glass-css-svg），真正的液态玻璃核心是 **SVG `feDisplacementMap` 作为 `backdrop-filter`** —— 这不是渐变/阴影能模拟的，它直接操作背景像素的采样位置，让边缘内容真正「弯曲」。

**新建 `js/liquid-glass.js`**：
- `generateDisplacementMap(edgeRatio)`：在 256×256 canvas 上逐像素计算位移贴图
  - R 通道 = X 位移，G 通道 = Y 位移，128 = 无位移
  - 边缘区域（默认 18% 宽度）：采样位置向外偏移 → 背景内容看起来向中心弯曲（凸透镜效果）
  - 中心区域：128 中性值 → 无折射
  - smoothstep 曲线确保平滑过渡
- `createFilter(scale, edgeRatio)`：创建 `<svg><defs><filter>` 含 `feImage`（位移贴图）+ `feDisplacementMap`（应用到 SourceGraphic），注入 `<body>`
- `window.updateLiquidGlass(scale, edgeRatio)`：公开 API，供设置面板调节强度

**CSS 改动 (`css/style.css`)**：
- 玻璃面板 `backdrop-filter: url(#liquid-glass-filter) blur(...) saturate(...)` — SVG 折射 + 磨砂模糊 + 色彩饱和度
- 新增浮动阴影（`box-shadow`）：sidebar/card/modal 下方有柔和投影，使玻璃面板看起来浮在背景上
- `::before` = 镜面高光（顶部亮线 + 左上角聚光），模拟环境光照射玻璃表面
- `::after` = 细微内边框（顶部亮线），定义玻璃边缘
- 折射强度 `--glass-refract` 控制 `::before`/`::after` 的 opacity

**JS 改动 (`js/settings.js`)**：
- `applyGlassRefract(percent)` 同时控制：
  - `--glass-refract` opacity（高光/边框可见度）
  - `updateLiquidGlass(scale)` SVG 位移强度（0~30px）

**HTML 改动**：引入 `js/liquid-glass.js`（在 katex 之后、core.js 之前）

**技术要点**：
- `backdrop-filter: url(#filter)` 仅 Chrome/Electron 支持（Safari/Firefox 不支持）
- 位移贴图通过 `preserveAspectRatio="none"` 拉伸适配任意面板尺寸
- `feDisplacementMap` 的 `scale` 参数控制最大像素位移（0~60px）

- 版本号：`20260722-r19`

## 液态玻璃可见性修复 (2026-07-22-r20)

用户反馈位移存在但弯曲不可见。根因是滤镜链顺序：`url(#filter) blur(16px)` 先位移再模糊，16px 模糊把位移效果抹平了。

**三处修复**：

1. **滤镜链顺序反转** (`css/style.css`)：`blur() saturate() url(#filter)` —— 先模糊再位移。平滑的模糊图案在边缘被位移弯曲，产生可见的「流动」效果。

2. **位移曲线改 t³** (`js/liquid-glass.js`)：`smoothstep` → `t³` 曲线。位移在边缘区域大部分接近 0，只在最边缘急剧增大，产生更锐利的「弯曲」感而非平缓的「凸起」。

3. **Scale 范围增大** (`js/settings.js`)：0~30px → 0~60px。默认值从 22 提高到 40。足够大的位移才能穿透模糊被看到。

- 版本号：`20260722-r20`

## 折射强度拆分为三个子项 + 辉光优化 (2026-07-22-r23)

**`glassRefract` 拆分为三个独立字段**：
- `glassCurve`（弯曲程度）→ SVG displacement scale，0~100 → 0~60px
- `glassDeflect`（偏折程度）→ edge zone width，0~100 → 0~0.4 edgeRatio
- `glassGlow`（顶层辉光）→ CSS `--glass-glow` 变量，0~100 → opacity 0~1

**新增三个 apply 函数**（替换 `applyGlassRefract`）：
- `applyGlassCurve(percent)` → `updateLiquidGlass(scale, undefined)`
- `applyGlassDeflect(percent)` → `updateLiquidGlass(undefined, edgeRatio)`
- `applyGlassGlow(percent)` → 设置 `--glass-glow` CSS 变量

**`updateLiquidGlass` 修复**：`scale` 参数为 `undefined` 时跳过更新，避免两个函数互相覆盖。

**辉光 CSS 优化**：
- `--glass-refract` → `--glass-glow`
- ::before 新增 `filter: brightness(calc(0.6 + var(--glass-glow) * 0.8))` — 高辉光值时更亮
- 顶部高光梯度更锐利（0.28 → 0.08 → 0.02），新增底部右侧环境反射
- 角落高光源心移到 15% 3%，新增 mid-stop
- ::after 边框新增 right/bottom 边色，形成完整边缘定义
- 暗色模式同步增强

**迁移**：`loadCustomTheme` 中旧 `glassRefract` 自动拆分为 `glassCurve` + `glassGlow`（同值），`glassDeflect` 默认 18。

- 版本号：`20260722-r23`（settings.js, style.css, liquid-glass.js）

## 卡片玻璃效果定位修复 (2026-07-22-r24)

**问题**：用户反馈侧边栏边缘玻璃效果好，但主界面 `.card` 效果差。

**根因**：`.card` 缺少 `position: relative`。`::before`（辉光）和 `::after`（边缘线）伪元素使用 `position: absolute; inset: 0`，但卡片没有定位上下文，导致伪元素定位到最近的定位祖先（或视口），完全错位/不可见。

对比：`.sidebar` 有 `position: fixed`（天然定位上下文），`.modal` 在玻璃样式中有 `position: relative`，唯独 `.card` 缺失。

**修复**：`css/style.css` 新增 `[data-glass="true"] .card { position: relative; }`

- 版本号：`20260722-r24`（style.css）
