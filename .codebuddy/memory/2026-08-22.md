# 2026-08-22

## 学习 tab：双指捏合缩放改为围绕捏合中心

**问题**：双指缩放 PDF 的实时预览固定从页面顶部/中心缩放（`transform-origin: center top`），用户在任何位置捏合效果都一样，不跟手指。

**改动**（`js/books-study.js`，`bkStudyBindPinchZoom`）：
- `touchstart`：记录 `_pinch` 扩展为 `{d0, scale0, cx0, cy0, pageLeft0, pageTop0}`——`cx0/cy0` 为捏合中心相对 wrap 的坐标，`pageLeft0/pageTop0` 为页面元素初始 `offsetLeft/offsetTop`。
- `touchmove`：`transform-origin: 0 0`，`transform = translate(tx,ty) scale(k)`，其中 `k = s/scale0`，`px = cx0 - pageLeft0`（捏合中心对应页面内容点），`tx = 当前中心cx - pageLeft0 - px*k`——保证**手指中心下的内容不动**，缩放跟随捏合中心。
- `touchend`/`touchcancel`：仍 `_stRenderPage()` 高清重渲染（回到居中，scale 保留）。
- `index.html`：books-study.js?v=20260821-r1 → r2；`service-worker.js` mst-v17 → v18。

**局限**：松手后 `_stRenderPage` 重建 DOM 丢失平移，页面回到居中（未保持捏合位置）。如需保持可后续给 `_stRenderPage` 加 translate 记忆。

## 学习 tab：松手后保持捏合位置（不跳回居中）

**改动**（`js/books-study.js` + `css/style.css`）：
- 新增状态 `_stPdfOff = {x, y}`（页面相对阅读区的平移偏移）。
- **页面定位改为 `position:absolute`**：`.bk-study-pdf-page` 由 `margin:0 auto` 居中改为 `position:absolute; left/top 由 JS 设置`；`.bk-study-stage` 加 `position:relative` 作定位基准。`_stRenderPage` 构建页面时：`left = baseLeft(居中) + _stPdfOff.x`、`top = 4 + _stPdfOff.y`；fit-width 时偏移强制 0。
- `touchmove`：额外记录 `_pinch.lastTx/_pinch.lastTy`。
- `touchend`：用 `lastTx/lastTy` 换算成相对**新居中基准**的偏移——`k = _stPdfScale/scale0`、`cssWNew = 页面scale0宽 * k`、`baseLeftNew = (wrapW - cssWNew)/2`、`_stPdfOff.x = (pageLeft0 + lastTx) - baseLeftNew`、`y` 同理（baseTop=4）——再 `_stRenderPage()` 高清重渲染，页面停在捏合处。
- `touchcancel`：重置 `_stPdfOff`。
- **偏移重置场景**：翻页（Prev/Next/Jump）、`bkStudyPdfFitWidth()`（适应宽度）都重置 `_stPdfOff = {0,0}`；切换章节由 `bkRenderStudyTab` 自然重置（状态变量在模块级）。

**注意**：页面 `position:absolute` 后，之前依赖 `margin:0 auto` 居中 + 超宽可滚动的行为改为 JS 计算 `baseLeft` 居中；`.bk-study-stage` 仍是 `overflow:auto`，超出时滚动。文本层（absolute 子元素）不受影响。

**验证**：`read_lints` 无错误。需完全重启 Electron + iPhone/iPad 真机验证。
