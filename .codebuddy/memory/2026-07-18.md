## LaTeX $$ 分隔符渲染修复

- 问题：AI 回复中用 `$$...$$` 包裹的块公式无法渲染，因为 `ai-render.js` 只处理 `\[...\]`/`\(...\)`
- 修复两处：（1）`wrapBareLatex` 增加 `$$` 分隔符识别，避免其内容被错误重包裹；（2）`formatMarkdownBase` 新增 `$$...$$` → KaTeX display mode 渲染步骤

## 待复习笔记 Bug 修复

- 问题：昨天编辑的笔记不在"今天"的"待复习笔记"中出现
- 根因：`getNotesDueForReview()` 用 `nextDate <= today` 比较，但 `nextDate` 保留了原始更新时间的时间成分（如 12:20、23:11），而 `today` 是当天 00:00，导致当天晚些时候才更新的笔记在当天不显示
- 修复：`js/notes.js` 中 `getNotesDueForReview` 的比较改为 `nextDate.toISOString().slice(0,10) <= todayStr`，只比较日期忽略时间
