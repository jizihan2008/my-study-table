## 修复：日报对话重复新建 v0.2.6

用户反馈：每日日报对话虽然存在，但有时还是新创建了一个。

### 根因（重要）
**`_dailyReport` 标记被两个降级保存清理逻辑误删**：
1. `js/core.js` 的 `saveData`（key=study_ai_convs 时）：`JSON.stringify` 失败降级清理会**删除所有 `_` 前缀字段**（含 `_dailyReport`/`_hasUnread`/`_hasUnreadAuto`）→ 日报标记永久丢失
2. `js/ai-utils.js` 的 `safeSaveAiConvs`：降级清理白名单（id/title/systemPrompt/autoTitled/createdAt/tree/activePath/messages）**不含 `_dailyReport`** → 同样丢失

标记丢失后，`getDailyReportConv()` 的 `aiConvs.find(c => c._dailyReport)` 找不到已有日报对话 → 新建一个 → 用户看到"日报存在却重复新建"。且清理只改 localStorage 不改内存 `aiConvs`，重启后从 localStorage 加载即丢标记。

### 修复（3 处）
- **settings.js `getDailyReportConv`**：查找加标题兜底 `aiConvs.find(c => c._dailyReport) || find(title === '📋 每日日报' || '☀️ 晨间日报')`；找到后回填 `_dailyReport=true` + 统一标题 + `autoTitled=true`（仅 changed 才 save）。
- **core.js `saveData`**：降级清理改为保留 `_dailyReport`/`_hasUnread`/`_hasUnreadAuto`（其余 `_` 前缀仍删）。
- **ai-utils.js `safeSaveAiConvs`**：清理白名单追加 `_dailyReport`/`_hasUnread`/`_hasUnreadAuto`。

## AI 附件：DeepSeek 等非视觉模型支持更多文本格式 v0.2.8

- 版本：package.json 0.2.7→**0.2.8**；index.html ai-attach.js 首次加版本 `20260807-r1`。node --check 通过、lint 0。

## 任务线：侧边栏可折叠 + 拖拽默认开启修复 v0.2.10

- **侧边栏可折叠**：新增 `tlSideCollapsed` 状态 + `tlToggleSidebar()`；`tlRenderSidebar` 折叠态只返回窄条展开按钮（`.tl-side-collapsed` 宽 44px，icon panel-left-open）；展开态第一张卡片头加折叠按钮（`.tl-side-card-head`，icon panel-left-close）。
- css：`.tl-sidebar` 加 width 过渡、`.tl-side-collapsed`、`.tl-side-toggle`、`.tl-side-card-head`。
- 版本：package.json 0.2.9→**0.2.10**；index.html taskline.js r8→`20260807-r9`、style.css r23→`20260807-r24`。node --check 通过、lint 0。
