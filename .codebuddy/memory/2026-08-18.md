## 全局关键词界面 + 笔记关键词功能（v20260818-r1）

用户需求：添加全局关键词界面（可查看/筛选某本书/笔记、搜索关键词），并为笔记系统添加关键词功能。已确认：笔记关键词 = AI 自动提取 + 手动增删；全局数据仅覆盖书籍术语 + 笔记关键词；点击关键词跳转到来源处。

### 改动文件
- **js/notes.js**（版本头注释改为 `v=20260818-r1`）：
  - `migrateNoteData()` 增加 `if (n.type==='note' && !Array.isArray(n.keywords)) n.keywords=[];`（tags 之后）
  - `createNewNote()` 对象追加 `keywords: []`
  - 新增 `renderNotesKeywordsInput()`（渲染 `.notes-keywords-bar` chips + 输入框 + AI 提取按钮）、`handleKeywordInputKey`（Enter/逗号提交）、`commitKeywordInput`（逗号/分号拆分去重）、`removeNoteKeyword(idx)`、`aiExtractNoteKeywords()`（复用 `getSummaryAiKey()` + fetch `{baseUrl}/chat/completions`，content 截断 6000，Prompt 要求输出纯 JSON 数组，`parseKeywordList()` 兜底解析，提取中按钮 disabled 显示"⏳ 提取中…"，失败 `showMiniToast` 反馈，成功合并去重 + 保存 + `renderNoteList()`）
  - `selectNote()` 与 `renderNotes()` 中在 `renderNotesTagInput()` 后新增 `renderNotesKeywordsInput()` 调用
- **js/keywords.js**（新文件，`v=20260818-r1`，加载顺序在 books-annot.js 之后、calendar.js 之前）：
  - `collectKeywordEntries()`：遍历 `booksData`→chapters→`kb.terms` 生成 `{word,type:'book',bookId,bookTitle,chapterId,chapterTitle,def}`；遍历 notes 中 `type==='note'` 且有 keywords 的生成 `{word,type:'note',noteId,noteTitle}`
  - `renderKeywords()`：搜索框（word/def/来源标题模糊匹配）+ 来源分段（全部/教材/笔记）+ 二级下拉（选择具体书/笔记，`String(id)` 比较），筛选状态存 `localStorage('study_keywords_filter')`
  - 主体按 word 分组（Map 单次遍历，频次徽标 + 书籍蓝色 chip / 笔记紫色 chip），hover 上浮高亮
  - `kwJump(type,id1,id2)`：书籍 → `switchTab('books')`+`bkSelectBook`+`bkSelectChapter`；笔记 → `switchTab('notes')`+`selectNote`（防御式 `typeof` 检查）
  - 空态：无数据提示先去构建教材知识库/提取笔记关键词；搜索无结果显示"未找到匹配关键词"
  - **关键点**：`booksData` 与 `notes` 是 core.js/books.js 顶层 `let` 全局变量（不在 window 上），直接引用即可；ID 比较统一用 `String()` 兼容
- **js/core.js**：`ALL_NAV_ITEMS` 在 books 后新增 `{ id:'keywords', icon:'key-round', label:'关键词' }`（`loadNavConfig` 会自动并入 order，侧边栏自动出现）；`switchTab` 新增 `if (tab==='keywords') renderKeywords();`
