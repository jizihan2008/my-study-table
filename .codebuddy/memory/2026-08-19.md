## 信息咨询：Windows Copilot 国内使用（未改动项目代码）
用户询问中国大陆如何使用 Windows Copilot。已检索最新资料并答复：
- 微软 Copilot 未对中国大陆开放，会提示"此区域当前不支持 Copilot"；需改系统区域（美国/英国）+ 合规网络环境 + 账号区域配合才能用国际版，有合规风险。
- 企业合规路径：Microsoft 365 Copilot 企业版（2024 起对国内开放，联网/Chat/文生图受限）、Azure 国际版 API。
- 世纪互联国内版 Microsoft 365/Azure 不含 Copilot。
