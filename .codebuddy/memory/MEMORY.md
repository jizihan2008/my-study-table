# 长期记忆

## 项目：我的学习桌面

### 技术决策与约定
- **版本发布策略·方案 B**（2026-08-02）：一律三位 semver，MAJOR=项目阶段（阶段一=`1.x.y`）、MINOR=向后兼容新功能、PATCH=bug 修复。全局唯一、单调递增、永不复用。禁止四位版本号（`0.1.11.1` 被 npm semver 判 null、electron-updater 抛 `ERR_UPDATER_INVALID_VERSION`）。当前 `0.1.x` 为初始开发期。
- **应用运行约定**：修改 `js/` 或 `css/` 后**必须完全重启 Electron**（窗口刷新不够，主进程注入脚本不重载）。
- **AI tool_call 参数解析**：`js/ai-tools.js` 的 `parseSingleToolCall` 必须用 `JSON.parse()` 解析 params，勿手动正则提取（不解码 JSON 转义，LaTeX 双反斜杠会渲染失败）。
- **笔记数据模型**：AI 创建的笔记必须含 `type:'note'` + `parentId`（非旧 `folderId`）。`renderItem` 限制递归深度 + `visited Set` 防循环；`resolveNoteFolderPath` 避免 self-parent。
- **AI 记忆画像**：`memory.profileText` 是单段自由文本（AI 每日自动生成），非分段字段；旧分段数据在 `loadAiMemory()` 自动迁移合并。
- **预设→自定义切换**（2026-07-22）：`js/settings.js` 的 `switchToCustomMode(cfg)` 是唯一切换入口，所有设置 handler 先调用它再改属性再 save，禁止内联 `cfg.preset='custom'`。
- **液态玻璃折射**（2026-07-22 r23）：三独立控制 `glassCurve`（SVG displacement 0~60px）/`glassDeflect`（edge zone 0~0.4）/`glassGlow`（`--glass-glow` 0~1）。`updateLiquidGlass(scale, edgeRatio)` 支持 undefined 跳过单参数。仅 Chromium 支持 `backdrop-filter: url()`。

### 模块架构
- **任务线系统**（2026-08-06，v0.2.7）：GTNH 式任务书，localStorage `study_taskline_v1`（version:3，**无经验系统**），主模块 `js/taskline.js`。双轴：主线 main（前一章全 done/skipped 解锁）+ 素质线 quality；**每章节一张独立 DAG 图，允许跨章节依赖**。`tlLayoutGraph` 按依赖深度分列（`tlComputeDepth` DFS+循环防护），SVG 贝塞尔箭头；状态 draft✏️/locked🔒/active▶️/done✅/skipped⏭️。v0.2.6 跨章节依赖：`.tl-node-ext` 虚线占位节点 + `.tl-edge-ext` 虚线边，点击 `tlGotoExternalQuest` 跳转。v0.2.7 手动画布：quest 增 `pos:{x,y}`，`tlLayoutGraph` 检测任一任务有 pos → 整章切手动布局 `tlLayoutGraphManual`；「拖拽」切换按钮 `tlDragMode` + `tlNodeDragStart`。条件 cond 自动检测（todo/note/timer/manual），`cond.done===true` 手动覆盖。奖励：徽章 `tlCheckAutoBadges` + 奖励池 `tlRewardBalance()=tlDoneCount()-store.spent`。AI 适配：ai-tools.js 12 个 `quest_*` 工具，`buildAiSummary()` 注入。待办联动：保存后调 `tlOnTodosChanged()`。**坑**：(1) quest_update 设 active 走 `tlRefreshQuestStatus`，勿直接调 tlActivateQuest；(2) 无 xp/等级函数，勿引入；(3) 占位节点不参与条件/解锁；(4) quest pos 是画布坐标，布局加 TL_PAD 偏移、拖动回写减 TL_PAD，pos 传 null 回退自动布局。
- **好友系统**（2026-08-05，v0.3.0）：Supabase（PostgreSQL+Auth+RLS+Realtime），建表 `supabase/schema.sql`。前端 `js/friends.js`（key `study_friends_config`、`getSupabaseClient` 单例、`computeDailyStats`+`syncStudyStats`）+ `js/friends-chat.js`（Realtime 订阅）。加载顺序 updater.js 后：supabase.js→friends.js→friends-chat.js。侧边栏「好友」nav id=friends、`section-friends`、设置页「好友」tab。**隐私红线**：只同步聚合统计，绝不上传待办/笔记内容，RLS `is_friend()` 保证可见性。SDK 经 `npm.cmd install @supabase/supabase-js@2 --no-save` 拷 UMD。**坑**：订阅回调动态流更新用 `renderFriendsFeedView` 手动 innerHTML，勿调不存在的 renderFriendsFeed。
- **AI 树状对话**（2026-08-03）：`conv.tree` 节点字典 + `conv.activePath` + `conv.messages`（活跃路径扁平缓存）。核心 API `js/ai-tree.js`：ensureTree/migrateConvToTree/appendMessage/createBranch/switchBranch/recomputeMessages/resetConvTree/trimConvMessages/branchInfoAt/siblingBranchCount/siblingNodeIds。**写消息一律 `appendMessage(conv,msg)`，禁止直接 `conv.messages.push`**。候选/重新生成 = user 节点下兄弟分支；「换一条」调 `regenerateAiMessage(nodeId)`。渲染遍历 `activePathNodes`；「分支树」浮层。脚本加载顺序：ai-utils→ai-tree→ai-conv→ai-attach→ai-render→ai-tools→ai-search→ai-api→ai-send。
- **AI 模块拆分**（2026-07-18）：`js/ai.js` 拆为 9 模块（含 ai-tree.js），按依赖顺序在 index.html 加载，备份 `js/ai_backup_20260718.js`。
- **扩展系统**（2026-08-04，v0.1.14+0.1.15）：外部扩展存 `~/.my-study-table/extensions/<id>/`。两类：`plugin`（受限 `window.extAPI` 白名单）与 `patch`（`PatchEngine.override/wrap/revertExt` 运行时覆盖）。主进程 IPC 全 `isPathInside` 白名单校验。渲染层：ext-api.js/patch-engine.js/ext-manager.js/codegen.js。**CodeBuddy CLI Agent 模式**：`buildAgentPrompt/runAgent/parseAgentSummary/locateCli` spawn codebuddy CLI；`parseAgentSummary` 严格校验 type∈{plugin,patch}+id+name；流式日志 `createLogAppender`。CLI 关键点：包 `@tencent-ai/codebuddy-code`（Node≥18.20）；`-p --dangerously-skip-permissions --output-format stream-json`；**Windows 绕开 cmd.exe**：`resolveCliEntry` 解析 .cmd 真实入口 + `spawn(process.execPath,[script],{env:{ELECTRON_RUN_AS_NODE:'1'}})`；输出 `createStreamDecoder`（UTF-8 fatal 探针，失败切 gb18030）。登录检测：极简 `-p hi`，含 `Authentication required` 即未登录（12s 超时判已登录）。extAPI 异步 IPC 需 `.catch()` 吞 rejection。
- **教材图注识别**（2026-08-13，books-pdf.js `bkExtractCaptionsFromText`）：方案 A+B。**XObject 检测对矢量图教材无效**（《算法导论》整本插图是 constructPath+fill）——不要用图片 XObject 判定"该页有图"。核心算法：textContent items 按 `transform[5]`（y）容差 4px 聚合成行 → 行内按 x 排序 → 按 x gap>40px 拆栏 → 行首锚定 `^(?:Figure|Fig|图)\s*编号` → 正文引用过滤，**核心判据是"编号后首词必须大写"**（`bkFirstWordLowercase`，图注是标题性大写名词短语，跨行拆词导致的"行首 Figure"编号后紧跟小写词即丢弃）。补充：动词黑名单 `shows/illustrates...` + 中文词 `表示/说明...`。**易踩坑**：栏拆分 gap 必须用「上一 item 右边界 `x+width` 与当前 item x 之差」，不能用 item 起始 x 之差（pdf.js 会把整句合并成大 item）；图注跨行**不拼接**（取首行）。Node 加载 pdf.min.mjs：`pathToFileURL` + DOMMatrix polyfill + `GlobalWorkerOptions.workerSrc` 本地 worker；新版 `pdf.destroy` 不存在，用 `loadingTask.destroy()`。

### GitHub 发布经验
- **exe 补传**（2026-08-04 更新）：electron-builder `npm run publish` 上传 80MB exe 极易超时（0.1.11/0.1.13），release 只有 blockmap+latest.yml。**修复命令**（无需代理）：取 release id `curl https://api.github.com/repos/jizihan2008/my-study-table/releases/tags/vX.Y.Z` → `POST https://uploads.github.com/repos/jizihan2008/my-study-table/releases/{id}/assets?name=My-Study-Table-Setup-X.Y.Z.exe`（Header `Authorization: Bearer <GH_TOKEN>`+`Content-Type: application/octet-stream`，body `--data-binary @本地exe`）。资产名用连字符版本（与 latest.yml url 一致）。token 每次需用户重新提供；token 明文绝不写入记忆。
- **发布前置**（2026-08-02）：发布须 PowerShell 设 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:7892`（cmd /c 会让 app-builder 的 Go 代理解析失败）；手动下载 winCodeSign-2.6.0/nsis-3.0.4.1/nsis-resources-3.4.1 到 `%LOCALAPPDATA%\electron-builder\Cache\`；electron-builder 24.x 不支持 nsis.signAndEditExecutable（已删）；后端 node 用 `npm.cmd`（PowerShell 禁 npm.ps1）。已装 Git 2.55.0，仓库 main 分支。
