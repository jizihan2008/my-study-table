# 长期记忆

## 项目：我的学习桌面

### 技术决策与约定
- **版本发布策略·方案 B**（2026-08-02 确认）：一律三位 semver，MAJOR=项目阶段（阶段一=`1.x.y`…），MINOR=向后兼容新功能，PATCH=bug 修复。全局唯一、单调递增、永不复用。禁止四位版本号（`0.1.11.1` 会被 npm semver 判 null、electron-updater 抛 `ERR_UPDATER_INVALID_VERSION`）。当前 `0.1.x` 为初始开发期，发布 `1.0.0` 才进入阶段一。
- **应用运行约定**：修改 `js/` 或 `css/` 后**必须完全重启 Electron**（窗口刷新不够，主进程注入脚本不重载）。`js/taskline.js` 等渲染层 JS 修改后需重启生效。
- **AI tool_call 参数解析**：`js/ai-tools.js` 的 `parseSingleToolCall` 必须用 `JSON.parse()` 解析 params，勿手动正则提取（不解码 JSON 转义，LaTeX 双反斜杠会渲染失败）。
- **笔记数据模型**：AI 创建的笔记必须含 `type:'note'` + `parentId`（非旧 `folderId`）。`renderItem` 必须限制递归深度 + `visited Set` 防循环；`resolveNoteFolderPath` 避免 self-parent。
- **AI 记忆画像**：`memory.profileText` 是单段自由文本（AI 每日自动生成），非分段字段；旧分段数据在 `loadAiMemory()` 自动迁移合并。
- **预设→自定义切换**（2026-07-22）：`js/settings.js` 的 `switchToCustomMode(cfg)` 是唯一切换入口，所有设置 handler 先调用它再改属性再 save，禁止内联 `cfg.preset='custom'`。
- **液态玻璃折射**（2026-07-22 r23）：三独立控制 `glassCurve`（SVG displacement 0~60px）/`glassDeflect`（edge zone 0~0.4）/`glassGlow`（`--glass-glow` 0~1）。`updateLiquidGlass(scale, edgeRatio)` 支持 undefined 跳过单参数。仅 Chromium 支持 `backdrop-filter: url()`。

### 模块架构
- **任务线系统**（2026-08-06，v0.2.7）：GTNH 式任务书，localStorage `study_taskline_v1`（version:3，lines/quests/badges/rewards/spent/toggle，**无经验系统**），主模块 `js/taskline.js`。双轴：主线 main（`tlMainLineUnlocked` 前一章全 done/skipped 解锁）+ 素质线 quality。**每个章节一张独立 DAG 图**（不做全局合并），**允许跨章节依赖**（deps 为全局任务 ID，解锁逻辑天然支持）。**任务图为 GTNH 式平面 DAG**：`tlLayoutGraph(quests, extQuests)` 按依赖深度分列（`tlComputeDepth` DFS+循环防护，`_ext` 节点深度 0 不展开），SVG 贝塞尔箭头连线；`kind:main` 金框 / `kind:side` 蓝框；状态 icon draft✏️/locked🔒/active▶️/done✅/skipped⏭️。**v0.2.6 多线改造**：跨章节依赖渲染 `.tl-node-ext` 虚线灰框占位节点（章节角标）+ `.tl-edge-ext` 虚线边，点击 `tlGotoExternalQuest(id)` 切章节+滚动+`.tl-flash` 高亮；详情前置任务列表显示跨线章节名角标+「查看」跳转；图例仅在有外部依赖时显示「跨章节依赖」。**AI 防单链**：`buildAiSummary()` 每章列「关键任务锚点」[ID:xxx]（kind=main，限 6 个）+ 末尾 DAG 设计指导段；`quest_create/update` description 强化 DAG 警示，且 deps 有效性校验（引用不存在 ID 返回 ⚠️ 提示修正）。**v0.2.7 手动画布 + AI 摆位**：quest 增 `pos:{x,y}`（画布绝对坐标，节点左上角）；`tlLayoutGraph` 检测本章节任一任务有 pos → 整章切手动布局 `tlLayoutGraphManual`（有 pos 按坐标放、外部占位节点最左侧列、无 pos 任务排默认区、箭头仍按 deps 自动连）；图头部「拖拽」切换按钮（`tlDragMode`，`tlToggleDragMode`）+ 节点 `tlNodeDragStart`（区分点击/拖动，拖动写入 pos 后 renderTaskLine 重算连线）；`quest_create/update` 增 `pos` 参数、`quest_get` 显示 `📍 画布位置`。章节目录浮窗 `tlOpenChapterPanel`（章节/徽章/奖励三 tab），`tlSwitchLine` 切换章节。状态机 draft→locked/active→done/skipped；`tlRefreshAll()` 全局刷新（主线锁+deps 解锁+**仅 active 且有条件的任务**条件全满足自动完成）；无条件任务手动点完成。条件 cond 自动检测（todo→待办 done、note→笔记 content 非空、timer→`study_timer_records` 累计 ≥minutes、manual→done），`cond.done===true` 手动覆盖。奖励：徽章 `tlCheckAutoBadges`（1/5/10/15/20/30 阈值+章节达成）+ 奖励池（`tlRewardBalance()=tlDoneCount()-store.spent`）。AI 适配：`js/ai-tools.js` 12 个 `quest_*` 工具，`buildToolsSystemPrompt` 注入 `buildAiSummary()`。待办联动：todos.js `toggleTodo`、ai-tools.js `toggle_todo`/`batch_update_todos` 保存后调 `tlOnTodosChanged()`。**坑**：(1) quest_update 设 status=active 走 `tlRefreshQuestStatus` 重判定，勿直接调 tlActivateQuest（要求 status 必须 draft）；(2) 本系统无 xp/等级函数，勿引入；(3) 占位节点不参与条件/解锁逻辑（只读引用）；(4) quest pos 是画布坐标、布局时加 TL_PAD 偏移，拖动回写需减 TL_PAD；pos 传 null 清除回退自动布局。

### GitHub 发布经验
- **exe 补传**（2026-08-04 更新）：electron-builder `npm run publish` 上传 80MB exe 极易超时（0.1.11/0.1.13），release 只有 blockmap+latest.yml。**修复命令**（无需代理）：取 release id `curl https://api.github.com/repos/jizihan2008/my-study-table/releases/tags/vX.Y.Z` → `POST https://uploads.github.com/repos/jizihan2008/my-study-table/releases/{id}/assets?name=My-Study-Table-Setup-X.Y.Z.exe`（Header `Authorization: Bearer <GH_TOKEN>`+`Content-Type: application/octet-stream`，body `--data-binary @本地exe`）。资产名用连字符版本（与 latest.yml url 一致）。token 环境变量/gh CLI/electron-builder 缓存均不持久，每次补传需用户重新提供 GH_TOKEN；token 明文绝不写入记忆。
