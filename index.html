    对话标题自动生成
    每次 AI 回复后，自动为对话生成简短标题。关闭后对话标题保持默认名称。
    选择用于生成对话标题的 AI Key。若选择「使用当前对话的 Key」，则使用聊天中当前启用的 Key 来生成标题。
    日报设置
    选择用于生成晨间/晚间日报的 AI Key。若选择「使用当前激活的 Key」，则使用聊天中当前启用的 Key 来生成日报。
    晨间日报
    开启后每次打卡时自动生成晨间日报，回顾昨天、规划今天。
    手动触发一次今日晨间日报。
    晚间日报
    开启后每天指定时间自动生成晚间回顾，总结当天学习工作。
    超过此时间后，若今天尚未生成则自动生成晚间日报。
    强制生成一次今日晚间日报。
    今日聚焦设置
    每天最多可设置的聚焦任务数（2~5 个）。此设置会同步更新 AI 提示词中的限制描述。
    开启后会在每次 AI 对话的系统提示词中告知模型你是程序开发者，让它关注程序的优化建议和所需接口
    Supabase 连接
    好友系统和插件市场共用此 Supabase 项目连接。应用已内置默认项目（下方已自动填入），通常无需修改即可直接使用；如需接入自己的项目，替换 URL 与 anon key 后点「保存并重新连接」。建表脚本见 supabase/schema.sql。
    修改后需重新进入相应页面生效。

    对话摘要
    每次离开对话时自动生成，每日整合为总摘要注入 AI prompt。
    笔记摘要设置
    选择用于生成笔记摘要的 AI Key。若不设置则不会自动生成摘要。
    开启后，切换笔记/离开笔记页/窗口失焦时会自动更新摘要。关闭后仅在手动点击「更新」按钮时才会生成摘要。
    笔记复习间隔
    控制每次复习后的下次复习间隔。标准模式适合高频复习，宽松模式间隔翻倍。
    用逗号分隔天数，至少一个值。例如「1,3,5,10,20,40,80,160」。
    这将删除所有笔记文件夹，笔记不会丢失但需要重新分类，用于修复笔记显示问题。
    开启后可在「今天」页面手动编辑打卡状态，方便调试日报功能
    选择 AI 联网搜索使用的引擎。DuckDuckGo 无需配置即可使用，其他引擎需填写下方 API Key。
    Brave: https://api.search.brave.com/res/v1/web/search（免费 2000 次/月）
    Tavily: https://api.tavily.com（免费 1000 次/月）
    Exa: https://api.exa.ai/search（免费 1000 次/月）
    SearchAPI: https://www.searchapi.io/api/v1/search（免费 100 次/月）
    教材知识库
    构建教材章节知识库时，正文超过该字符数则只取头尾关键片段（各约 72%），控制 Token 消耗。数值越大知识越完整但消耗越大，默认 9000。
    章节讲解与全书问答 AI 携带最近多少轮对话作为上下文（每轮 = 一问一答）。0 表示不带历史对话，只发知识库与原文片段。默认 6。

    系统提醒
    设置智能提醒，帮助你保持学习节奏。消息会通过系统通知发送，包含友善的鼓励话语。
    每日打卡提醒 在指定时间尚未打卡时提醒
    如果到了这个时间还没有任何打卡，就会发送提醒。
    打卡后聚焦提醒 打卡后一段时间未开始聚焦计时时提醒
    打卡完成后，如果这段时间内没有开始今天的第一次聚焦计时，就会发送提醒。
    空闲聚焦提醒 长时间未进行聚焦计时时提醒
    如果距离上次聚焦计时结束超过这个时间，就会发送提醒。
    在此时间段内不发送空闲提醒，适合午休、晚饭等休息时段。
